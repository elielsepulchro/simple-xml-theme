# Simple Blog XML (`simple-blog-xml`)

Um tema minimalista, limpo e totalmente funcional para o **blog**, estruturado em um único arquivo XML. Ideal para criadores de conteúdo que buscam um design moderno, rápido e sem poluição visual.

---

## 🚀 Características

- **Design Minimalista:** Focado na legibilidade do texto e na experiência do usuário.
- **Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops.
- **Estrutura Limpa:** Construído utilizando a versão moderna de layouts do Blogger (v2/v3).
- **Fácil Customização:** Estilos CSS fáceis de editar diretamente no código ou através do painel.

---

## 📥 Como Instalar

Siga os passos abaixo para aplicar este tema no seu blog:

1. Baixe ou copie o código contido no arquivo `theme.xml` deste repositório.
2. Acesse o painel administrativo do seu blog.
3. No menu lateral esquerdo, clique em **Tema**.
4. No card do seu tema atual, clique na **seta para baixo** (ao lado do botão *Personalizar*).
5. Selecione **Restaurar** e depois clique em **Fazer upload**.
6. Escolha o arquivo `theme.xml` do seu computador e aguarde a conclusão.

---

## 🎨 Customização Básica

Se você quiser alterar as cores ou fontes principais diretamente no código, abra o arquivo `theme.xml` e localize a tag `<b:skin><![CDATA[`. Lá você encontrará regras como:

```css
body {
    font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;
    background-color: #f9f9f9;
    color: #333333;
}
```

Basta alterar os valores de `background-color` ou `color` para ajustar o visual ao seu gosto.
